# 青鸟集群部署指南

本指南面向生产环境。免费版授权仅支持单节点部署，集群模式需要专业版或企业版授权。

第一步是环境准备。集群至少需要三台机器：两台运行 broker 与接入网关，一台运行元数据存储。推荐规格为 8 核 16 GB 内存、SSD 磁盘，操作系统使用 Linux 内核 5.x 以上。所有节点之间必须开启 NTP 时钟同步，时钟偏差超过 500 毫秒会导致副本复制协议拒绝工作。此外需要在防火墙上放通 9520（客户端接入）、9521（节点间复制）与 9530（元数据）三个端口。

第二步是初始化元数据存储。在元数据节点上执行 qnctl metadata init，该命令会生成集群唯一标识与根证书。初始化完成后启动元数据服务，并确认其健康检查接口返回 ok，再继续后续步骤。

第三步是启动 broker 与接入网关。在每台业务节点上，先将元数据服务地址写入配置文件，然后依次启动 broker 进程与网关进程。网关启动时会向元数据服务注册自身，可以通过 qnctl nodes list 确认所有节点都已出现在集群视图中。

第四步是配置副本与健康检查。将主题的默认副本因子设置为 3，确保任意单节点故障不丢数据；同时为每个节点配置存活探针，探测间隔建议 10 秒。完成后使用 qnctl cluster verify 做一次端到端验证，确认发布与订阅链路全部畅通。

最后是滚动升级注意事项。升级时应先升级元数据服务，再逐台升级 broker，每升级一台都要等待副本追平后再继续，避免同时重启两台以上节点导致分区不可写。
