# 青鸟常见问题 FAQ

## Q：青鸟支持哪些客户端平台？

A：官方 SDK 覆盖 Android、iOS、Web（WebSocket）、Python 与 Go；嵌入式设备可以使用任何标准 MQTT 3.1.1 客户端直连接入网关。

## Q：如何重置 API 密钥？

A：登录控制台，进入「项目设置 → 密钥管理」，点击目标密钥右侧的「重置」按钮。重置后旧密钥立即失效，正在使用旧密钥的连接会在下一次心跳时被断开，请先在业务低峰期更新客户端配置再执行重置。

## Q：免费版每月的消息配额是多少？

A：免费版每月包含 10 万条消息配额，单条消息最大 4 KB。配额用尽后新消息会被直接拒绝（不进入队列），配额在每月 1 日零点自动重置，无法累积到下月。

## Q：专业版每月的消息配额是多少？

A：专业版每月包含 5000 万条消息配额，单条消息最大 256 KB，超出部分按实际用量阶梯计费，可在控制台设置用量告警阈值。

## Q：如何删除一个不再使用的主题？

A：在控制台的主题列表中选择目标主题，点击「删除」。删除前必须先解除该主题上的全部订阅关系，否则会提示操作被拒绝；删除后主题内未投递的消息会被一并清除且不可恢复。
